Role Hierarchy Implemented:
──────────────────────────

✅ analyst_jr
   - View: Dashboard, Carte, Alertes, Renseignement, Signalements
   - Can: Escalate to chief
   - Cannot: Decide, manage users

✅ analyst_sr
   - View: ↑ + Collecte, Analyse, Rapports
   - Can: ↑ + Launch scans, generate reports
   - Cannot: Officially decide

✅ chief (Chef d'équipe)
   - View: ↑ + Endpoints, Reports Validation
   - Can: ↑ + Decide escalations, reassign analysts
   - Cannot: Manage system

✅ director (Directeur)
   - View: ALL + Audit, Journal d'Audit
   - Can: ↑ + Override, transmit to authorities
   - Cannot: (none - full operational access)

✅ admin
   - Can: Everything
   - Access: Full system + users + configuration

✅ auditor (Auditeur CEC)
   - View: Audit, Rapports (read-only)
   - Can: Annotate, flag anomalies
   - Cannot: Modify signalements


Workflows Implemented:
─────────────────────

Signalement Workflow:
  Citizen Report → Signalement Creation → Analyst Review →
  Escalate/Decide → Chief Review (if escalated) →
  Decision (Validé/Rejeté/Further Escalade) →
  Transmit to Authority → Close & Archive

SLA Enforcement:
  - 24-hour deadline from creation
  - Warning at 6 hours remaining
  - Director escalation if missed
  - Audit trail records all SLA breaches

Notification Triggers:
  - Escalation: analyst → chief
  - SLA Warning: < 6h remaining
  - Decision Needed: escalation awaiting decision
  - Transmission: decision approved & sent to authority


Security Improvements:
─────────────────────

✅ Route Protection
   - All /admin/* routes require authentication + permission
   - No route accessible with just isAuthenticated
   - Unauthorized access redirects to dashboard

✅ OTP Authentication
   - Email-based code (10-minute expiration)
   - Code verified before token issued
   - Logs contain OTP for dev mode auditing

✅ Permission Enforcement
   - 6 RBAC roles with distinct permissions
   - Fine-grained permission checks on all endpoints
   - Audit logs all access attempts

✅ Audit Trail
   - Every action logged with timestamp, user, role
   - Append-only (immutable) audit logs
   - Exportable for ethics committee review
